## Hardware requirements
Please make sure to check the system specifications on your MRI system and adjust critical parameters (maximum gradient strength and slew rate). Run the timing and gradient checks prior to execution on the scanner! seq.checkTiming() and seq.testReport()  
Our measurements were carried out on the following MRI system:
- Siemens MAGNETOM Prisma, 3T
- max. gradient strength = 35mT/m
- max. slew rate = 170T/m/s

## Installation and usage

1. Install MATLAB and download the original [Pulseq MATLAB source code](https://github.com/pulseq/pulseq). Add its `matlab` directory to your MATLAB path. **Tested with the Pulseq source available on November 12, 2026.** No additional MATLAB toolboxes or external packages are required for the supplied example.
2. Keep `OREX_test.m` and `pulseq_objects.mat` in the same working directory. The MAT file contains precomputed adiabatic half-passage (AHP) pulses and spiral-readout objects generated using [OpenMRF](https://openmrf.org).
3. Run `OREX_test.m` in MATLAB. The script constructs the sequence, checks timing, plots the sequence, and writes `OREX_test.seq`.

**Implementation notes:** The supplied spiral readout is fixed to the acquisition geometry used in the manuscript (**96 × 96 matrix, 256 × 256 mm² field of view, 5 mm slice thickness**). Changing these parameters requires regenerating the spiral gradients. The example uses a conventional slice-selective **sinc refocusing pulse**, whereas the study used an **SLR-designed pulse**. The SLR pulse can be generated for Pulseq using the Python **SigPy** package; its design parameters are documented in `OREX_test.m` (`flip angle = π`, `duration = 5 ms`, `TBW = 3`, `ptype = 'se'`, `ftype = 'ls'`, `d1 = d2 = 0.01`, `cancel_alpha_phs = false`). SigPy is **not required** to run the supplied example.

## Physical experiment

OREX measures the full transverse magnetization generated by **rotary excitation (REX)** during a continuous-wave spin-lock preparation. A weak oscillating field parallel to the main magnetic field drives a resonant response when its frequency matches the spin-lock frequency. After spin-locking, an adiabatic pulse and slice-selective 180° refocusing module preserve the REX-induced signal for a single-shot spiral readout, while returning the remaining spin-locked magnetization to the longitudinal axis for subsequent repetitions.

In this example, a **120 Hz**, **10 nT** sinusoidal field is emulated by a z-gradient at a slice offset of **10 mm** from isocenter. The spin-lock duration is **100 ms** at **120 Hz**; **20 evenly spaced stimulus phases** are acquired following three dummy scans. Phase variation produces the characteristic circular distribution of complex OREX signals described in the manuscript.
